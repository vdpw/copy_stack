# Troubleshooting

## Clipboard Changes Do Not Appear

Check:

- the desktop app, not only `pnpm dev`, is running;
- the published `copy_event_listener = "0.1.2"` dependency resolved;
- the clipboard event has a supported public representation;
- compact mode is not hiding a non-text event;
- the event is not marked concealed, transient, or autogenerated;
- the event did not exceed a resource budget.

Protocol skips are intentionally silent and leave no database, tray, UI, or
JSONL trace. Resource-limit failures emit a localized History notice with only
a safe reason code/size bucket. Debug logs contain control-flow facts but must
not include bodies, source identifiers, hashes, HTML, or paths.

## History Shows Only The First Items

This is expected paging behavior. The first response contains 50 summaries.
Use Load more for the next cursor page. The backend caps requests at 100 and
does not provide an all-history command.

If load-more fails, dismiss/retry the structured error. A refresh intentionally
returns to the first page while preserving the visible scroll anchor when
possible.

## An Expanded Preview Is Missing

Rich detail is loaded only after an eligible card is expanded. It can be
omitted when:

- HTML/image/detail budgets would be exceeded;
- a local image/video path is relative, a symlink, non-regular, changed during
  validation, missing, or unsupported;
- a PNG dimension header exceeds the pixel budget;
- compact mode intentionally suppresses rich detail.

The list summary and restore operation can still work when display-only detail
is unavailable.

## A Second Launch Does Not Create A New Window

This is expected. Copy Stack is single-instance. The later process exits before
database, listener, tray, or mirror setup and asks the existing process to show,
unminimize, and focus its main window.

If activation fails, confirm the first process is alive and inspect the safe
`MAIN_WINDOW_*` debug code. The callback intentionally ignores the later
process's arguments and current directory.

## Launch At Login Does Not Persist

Settings reads the OS login item, not SQLite. Every write is read back and a
mismatch is an error.

- Test a packaged app; development runners can behave differently.
- Reopen Settings for a fresh authoritative read.
- Check macOS login-item policy/security software.
- If the app moved, disable and re-enable the login item from the new location.

An autostart launch uses `--copy-stack-autostart`, keeps the main window hidden,
and should still create exactly one listener and tray.

## Database Initialization Or Permission Failure

Expected modes are:

```text
$HOME/.copy_stack                  0700
$HOME/.copy_stack/copy_stack.db    0600
SQLite sidecars                    0600
JSONL and mirror temp files        0600
```

Inspect with:

```bash
stat -f '%Sp %Su %N' "$HOME/.copy_stack" "$HOME/.copy_stack/copy_stack.db"
```

Startup deliberately rejects symlinks, non-regular/wrong-owner/multiply-linked
files, insecure directories, and missing owner permissions. It does not switch
to a less-private fallback. Fix the target ownership/type/permissions or move a
sanitized backup aside and retry.

For isolated debug QA, use a directory returned by bare `mktemp -d` on macOS.
A fixed child directly under `/tmp` or `/private/tmp` is rejected because its
immediate parent is public. Confirm the terminal reports `database initialized`
before interacting with the QA build; otherwise stop instead of continuing in a
failed startup state.

Do not delete or upload a real clipboard database while troubleshooting.

## Migration Fails Or Repeats

Inspect only schema metadata first:

```bash
sqlite3 "$HOME/.copy_stack/copy_stack.db" "PRAGMA user_version;"
sqlite3 "$HOME/.copy_stack/copy_stack.db" "SELECT key, value FROM app_metadata ORDER BY key;"
sqlite3 "$HOME/.copy_stack/copy_stack.db" ".schema clipboard_events"
```

Migrations are transactional. A failure should preserve the original table. A
current schema/classifier version validates shape and indexes but does not
decode or rebuild every row. Repeated full migration indicates version,
metadata, shape, or index validation is not reaching the current contract.

Legacy `sort_order` exists only as migration input; current ordering is
`timestamp DESC, content_hash ASC`.

## History Is Trimmed Earlier Than Expected

Both limits apply:

- `max_items`;
- `max_history_bytes` (256 MiB by default).

Inspect safe aggregate values:

```bash
sqlite3 "$HOME/.copy_stack/copy_stack.db" "SELECT key, value FROM settings WHERE key IN ('max_items', 'max_history_bytes') ORDER BY key;"
sqlite3 "$HOME/.copy_stack/copy_stack.db" "SELECT COUNT(*), COALESCE(SUM(byte_count), 0) FROM clipboard_events;"
```

Cleanup removes oldest rows until both constraints are satisfied.

## Menu Bar Is Empty Or Short

The menu bar intentionally reads at most 20 bounded summaries. Compact mode can
hide image/file/video rows. `show_in_menu_bar = false` hides the icon entirely.
Menu construction never decodes event blobs or reads local rich media.

## JSONL Is Missing Or Stale

Confirm both startup flags reached the app through Tauri's extra `--` separator
and that the destination is a private, current-user-owned regular-file path.

The mirror is asynchronous and debounced for 200 ms. Rapid mutations coalesce
to the newest generation. The worker writes a same-directory temporary file,
syncs it, and atomically replaces the destination; the last valid snapshot is
kept after a failed/superseded write.

Exit waits at most two seconds for the latest generation. A slow or failed
destination can produce `history_mirror_failed` while database mutations remain
committed.

## UI Shows A Generic Operation Error

This is intentional redaction. The IPC error contains only:

```text
code, operation, retryable
```

The diagnostic envelope adds only timestamp, version, platform, and
architecture. It never includes a clipboard body, hash, source identifier,
HTML, file path, SQL, or raw OS/plugin error. Use the operation/code and
synthetic reproduction steps rather than asking users for private history.

## HTML Preview Looks Simpler Than The Source

Active elements, scripts, forms, handlers, URLs, embedded images, unsafe styles,
SVG/MathML, and external resources are removed. Oversized, deeply nested, or
node-heavy HTML is rejected. The preview iframe has an empty sandbox and
`default-src 'none'; img-src 'none'`. This is a security boundary, not a
rendering bug to solve by weakening CSP or capabilities.

## Build Or CI Fails

Run the same gates locally:

```bash
pnpm install --frozen-lockfile
pnpm security-check
pnpm type-check
pnpm lint
pnpm test
pnpm build
cargo fmt --manifest-path src-tauri/Cargo.toml -- --check
cargo check --manifest-path src-tauri/Cargo.toml
cargo test --manifest-path src-tauri/Cargo.toml
```

CI runs natively on both `macos-15` Apple Silicon and `macos-15-intel`. A
failure on only one runner may be architecture/platform-specific. Successful CI
still does not complete the manual matrix in
`docs/security-release-checklist.md`.
