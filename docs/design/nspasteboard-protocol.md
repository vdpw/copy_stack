# NSPasteboard Protocol Policy

## Status

Accepted design for clipboard capture, history, export, and restore on macOS.

The marker names and their meanings follow
[NSPasteboard.org](https://nspasteboard.org/). This document defines Copy
Stack's product policy where the protocol leaves clipboard historians a choice.

## Goals

- Never retain or display clipboard contents marked as transient,
  autogenerated, or confidential.
- Apply one event-wide decision before content hashing, compact-mode
  projection, preview generation, persistence, tray synchronization, or JSONL
  export.
- Preserve protocol source and remote-device provenance without allowing that
  metadata to change content identity.
- Make full and compact modes follow the same privacy policy.
- Restore accepted history with one canonical source marker.
- Avoid logging clipboard contents or protocol source values.

## Marker Decision Table

The decision applies to the complete clipboard event. A marker on any
pasteboard item applies to all items in that event. Marker detection checks the
exact type name and never depends on whether the marker payload is empty.

| Marker | Category | History | Database and JSONL | History UI | Tray label | Restore |
| --- | --- | --- | --- | --- | --- | --- |
| `org.nspasteboard.TransientType` | Universal transient | Skip | No row or JSONL line | Hidden | Hidden | Not applicable |
| `de.petermaurer.TransientPasteboardType` | TextExpander/Butler transient | Skip | No row or JSONL line | Hidden | Hidden | Not applicable |
| `com.typeit4me.clipping` | TypeIt4Me transient | Skip | No row or JSONL line | Hidden | Hidden | Not applicable |
| `Pasteboard generator type` | Typinator transient | Skip | No row or JSONL line | Hidden | Hidden | Not applicable |
| `org.nspasteboard.ConcealedType` | Universal confidential | Skip | No row or JSONL line | Hidden | Hidden | Not applicable |
| `com.agilebits.onepassword` | 1Password confidential | Skip | No row or JSONL line | Hidden | Hidden | Not applicable |
| `org.nspasteboard.AutoGeneratedType` | Not explicitly copied by the user | Skip by default | No row or JSONL line | Hidden | Hidden | Not applicable |
| `org.nspasteboard.source` | Source bundle identifier | Record if otherwise supported | Store parsed metadata; accepted JSONL mirrors may include it | Localized source badge when usable | Omit to keep menu labels bounded | Write one canonical source marker |
| `com.apple.is-remote-clipboard` | Copied from another Apple device | Record if otherwise supported | Store a boolean; accepted JSONL mirrors may include it | Localized remote-device badge | Omit to keep menu labels bounded | Preserve as one presence marker |

Application-private data types which are not protocol markers keep their
existing behavior. They may remain in the stored event when that event has a
supported public representation, but they are not decoded for previews and do
not participate in the content hash.

## Combination Precedence

Copy Stack uses the strictest event-wide result:

1. Concealed, including the 1Password marker.
2. Transient, including the three proprietary transient markers.
3. AutoGenerated.
4. Recordable source, remote, or ordinary content.

All of the first three results skip history. The ordering makes the reason
deterministic for tests and diagnostics:

- Concealed plus any other marker is concealed and skipped.
- Transient plus AutoGenerated is transient and skipped.
- Source or remote never overrides a skip marker.
- Remote by itself is not transient and remains recordable.

Copy Stack does not read source metadata from an event after a skip marker has
been found. Skip-marker payloads are never inspected.

## Source Semantics

`org.nspasteboard.source` is parsed as strict UTF-8 without trimming,
normalizing, resolving, or guessing an application:

| Captured state | Stored metadata | History display | Restored payload |
| --- | --- | --- | --- |
| Marker absent | `NULL` | No source badge | Empty UTF-8 string |
| Marker contains valid bundle identifier | Exact string | Localized prefix plus exact identifier | Exact string |
| Marker contains empty UTF-8 string | Empty string, not `NULL` | Localized unknown-source badge | Empty string |
| Marker contains invalid UTF-8 | `NULL` | No source badge | Empty UTF-8 string |

When malformed or conflicting source markers appear on multiple items, the
first source marker in pasteboard item order is authoritative. A malformed
first marker is treated as unknown; a later marker is not used to replace it.

Source metadata is informational only. It never participates in normalized
content hashing or ordering. Copy Stack must not infer source from the active
application, resolve an unrelated foreground process, or create an
application-private source marker.

## Remote Clipboard Semantics

`com.apple.is-remote-clipboard` is a presence marker. Its payload is ignored.
It is independent from `org.nspasteboard.source`: a remote event can have a
valid source, an explicit unknown source, or no source marker.

Remote provenance does not participate in the content hash. Restoring an
accepted remote event preserves the provenance marker in both full and compact
modes.

## Capture Pipeline

The required order is:

1. Receive the event from `copy_event_listener`.
2. Assess protocol markers across all items.
3. Stop immediately when the policy says to skip.
4. For an accepted event, parse source and remote metadata.
5. Apply compact-mode content projection when enabled.
6. Classify supported public content and compute its normalized hash.
7. Apply restore suppression.
8. Insert or update SQLite, commit, and schedule the optional JSONL snapshot.
9. Rebuild the tray and notify frontend windows.

This order prevents skipped content from reaching content hashing, preview
generation, persistent storage, the tray, the frontend, or JSONL.

Prepared-row insertion and a version-gated metadata migration apply the same
assessment as the live capture loop. Rechecking at the persistence boundary
provides defense in depth for direct callers and removes disallowed legacy rows
when a migration is actually required. A current schema/classifier version does
not rescan or rebuild history on every startup.

## Persistence And Deduplication

Protocol metadata belongs beside, rather than inside, normalized content
identity. The history schema stores:

- nullable source bundle identifier metadata which preserves an explicit empty
  string;
- a remote-clipboard boolean;
- the existing encoded event used for full-mode restore.

When the same supported content is captured again, the existing row keeps its
history position while its event payload, source, and remote metadata are
updated to match the latest accepted copy. Source and remote changes alone do
not create another row.

A version-gated schema/classifier migration derives trustworthy source and
remote metadata from the encoded pasteboard event. It must not reuse the removed
legacy `source_app` column, whose foreground-application heuristic was
inaccurate. Rows carrying a skip marker are removed in that transactional
migration before initial JSONL, tray, or frontend reads.

## Compact Mode

Protocol assessment always runs on the original event before compact-mode
projection removes non-text flavors. Compact mode therefore:

- skips the same transient, concealed, and autogenerated events as full mode;
- retains source and remote metadata in their dedicated database fields;
- continues hashing only the accepted plain-text representation;
- restores plain text plus canonical source and remote markers.

Toggling compact mode does not make a previously skipped event observable.

## Canonical Restore

Before writing a stored event to the general pasteboard:

1. Remove every existing `org.nspasteboard.source` and
   `com.apple.is-remote-clipboard` occurrence from all items.
2. Add exactly one `org.nspasteboard.source` value to the first item.
3. Use the stored bundle identifier, including an explicit empty string, or an
   empty string when source metadata is unavailable.
4. Add exactly one empty `com.apple.is-remote-clipboard` marker to the first
   item when the stored remote flag is true.
5. Compute restore suppression from the body content; protocol metadata must
   not change the suppression hash.

Main-window and tray restores use the same preparation helper.

## Presentation

History cards may show two independent, localized badges:

- source, using the exact captured bundle identifier or a localized
  unknown-source label for an explicit empty string;
- copied from another device.

Missing or invalid source metadata produces no source badge. Tray item labels
remain based only on the content preview; source and remote suffixes are
deliberately omitted so metadata cannot create oversized native menus.

## JSONL And Logging

The optional JSONL history file is an explicit local mirror and can contain
accepted clipboard contents and their protocol metadata. A skipped event must
produce no row at all, including during a version-gated migration.

Database mutations send only a row-free refresh signal after commit. The worker
coalesces bursts, opens an independent read-only database connection for the
latest committed projection, writes a private same-directory temporary file,
flushes and syncs it, and atomically replaces the destination only when that
generation is still newest. JSONL database reads, decode, serialization, and
filesystem I/O never occur while holding the application's database mutex.

Normal and debug logs may record only control-flow facts such as a generic skip
or successful restore. They must not include:

- clipboard body bytes or previews;
- source bundle identifier values;
- concealed marker payloads;
- hashes presented as a substitute for logging sensitive contents.

Tests and documentation use synthetic values only. Never place real passwords,
password-manager output, user clipboard databases, or JSONL mirrors in the
repository.

## Verification

Table-driven Rust tests cover:

- every universal and proprietary marker;
- empty and non-empty marker payloads;
- markers on later pasteboard items;
- pairwise precedence combinations;
- valid, empty, missing, malformed, and conflicting source markers;
- remote marker presence;
- canonical restore marker replacement;
- full and compact capture;
- normalized hash independence;
- persistence, migration, preview, tray, and JSONL invisibility for skipped
  events.

Desktop QA on macOS must additionally use synthetic pasteboard values to check
the real `NSPasteboard` read/write path, both restore entry points, both restore
ordering settings, compact and full modes, three UI languages, a transient text
expander workflow, and Universal Clipboard from another Apple device.
