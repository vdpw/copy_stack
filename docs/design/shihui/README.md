# 拾回 · Brand concept

**名字：拾回**

把复制过的内容，随时找回来。

“拾”表达收集，“回”表达重新取用。中文作为主品牌；Shihui 是辅助拼音，
用于需要拉丁字母的展示场景。

## Icon

石墨灰圆角方形底座、米白回字形符号和一小段系统蓝。开口的外轮廓与
向内回转的形状表达找回内容；图形采用平面几何风格和非常轻的明暗层次。

配色参考当前界面：`#292726`、`#202023`、`#f3f3f5`、`#0068df`。
生成图稿的实际颜色是这些设计色的视觉近似。

使用内置 imagegen 生成。完整提示词保存在 `prompt.txt`。

## Files

- `shihui-icon.png` — 生成的透明背景高清设计稿。
- `icon-128.png` — 128 px 预览。
- `icon-32.png` — 32 px 预览。

尺寸预览通过 macOS `sips` 导出，并用于检查小尺寸轮廓与对比度。
这份目录交付品牌设计方案；应用显示名称和正式打包图标尚未接入。

Rill 已用于 Mac 知识管理工具，因此未采用这些英文候选：
